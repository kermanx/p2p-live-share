# CRC Live Share (PUC Minas)

Uma alternativa peer-to-peer e open-source para colaboração em tempo real, adaptada especificamente para o ecossistema **Octo** e o orquestrador **Devocto** da PUC Minas.

Esta extensão permite a edição colaborativa entre alunos e professores sem a necessidade de infraestruturas centralizadas proprietárias ou contas externas.

## Funcionalidades principais

- **Edição Colaborativa:** Vários alunos editando o mesmo código simultaneamente.
- **Suporte a Salas Grandes:** Escalonamento de cores otimizado para turmas de até 60 participantes.
- **Terminal Partilhado:** Professores podem partilhar o acesso ao terminal com alunos.

- **Sincronização de Seleção:** Veja exatamente o que o seu colega está a selecionar em tempo real.


## Colaboração no Octo

Diferente da versão original, o **CRC Live Share** foi modificado para:
- **Remover bloqueios de login:** Não é necessário conta GitHub ou Microsoft.
- **Privacidade Local:** Prioriza conexões dentro da rede interna da universidade.
- **Customização Visual:** Identidade visual alinhada aos padrões laboratoriais da PUC Minas.
